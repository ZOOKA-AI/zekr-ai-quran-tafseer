## Overview

Zekr AI is an Islamic knowledge platform providing AI-powered Quranic interpretation and tafseer. The application combines modern UI/UX with Islamic scholarship to make Quranic knowledge accessible to everyone.

## ✨ Features

- 📖 **Quranic Content** - Complete Quran with AI-powered interpretation
- 🤖 **AI Tafseer** - Intelligent Islamic scholarship insights
- 🎨 **Modern UI** - Beautiful, responsive interface
- ⚡ **Fast Performance** - Optimized with Vite
- 🌍 **Multi-language** - Support for multiple languages
- 📱 **Mobile Friendly** - Works seamlessly on all devices
- 🔍 **Search** - Advanced search capabilities
- 🎯 **Interactive** - Interactive learning tools

## 🛠️ Prerequisites

- Node.js 18 or higher
- npm or yarn

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/ZOOKA-AI/zekr-ai-quran-tafseer.git
cd zekr-ai-quran-tafseer

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev

# Open browser - server runs at http://localhost:5173
```

### Build & Preview

```bash
# Build for production
npm run build

# Preview production build
npm run preview

# Type checking
npm run typecheck

# Linting
npm run lint

# Fix linting issues
npm run lint:fix
```
