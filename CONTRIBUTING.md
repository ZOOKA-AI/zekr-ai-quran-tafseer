# Contributing to Zekr AI Quran Tafseer

We welcome contributions from the community! This document outlines how to contribute to this project.

## Getting Started

1. Fork the repository
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/zekr-ai-quran-tafseer.git
   cd zekr-ai-quran-tafseer
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Running Locally
```bash
npm run dev
```

### Building
```bash
npm run build
```

### Type Checking
```bash
npm run typecheck
```

### Linting
```bash
npm run lint
npm run lint:fix
```

## Making Changes

1. Make your changes
2. Test your changes locally
3. Run linting: `npm run lint`
4. Commit with clear messages:
   ```bash
   git commit -m "feat: add feature description"
   ```
5. Push to your fork
6. Create a Pull Request with a clear description

## Code Style

- Use ESLint for linting
- Use TypeScript for type safety
- Follow existing code patterns
- Add comments for complex logic
- Use Tailwind CSS for styling

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure CI passes
4. Request review from maintainers
5. Address review feedback

## Reporting Issues

Use GitHub Issues to report bugs or suggest features. Include:
- Clear description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Environment details
