# بوابة قبول النموذج على جهاز فيه WebGPU

هذه الصفحة تخصّ البند الذي **لم يُختبر** في بيئة التطوير: تشغيل النموذج الصغير داخل التطبيق على كرت شاشة حقيقي.
بيئة الخادم التي بُني فيها الفرع لا تحتوي WebGPU، فأي رقم يُنشر من هناك سيكون مخترعًا.

## التشغيل
```bash
VITE_BASE44_APP_ID=692235dc089d5988e8a95db7 \
VITE_BASE44_BACKEND_URL=https://base44.app \
VITE_ENABLE_LOCAL_SIMPLIFY=true npm run build
npx vite preview --port 4192
```
افتح `http://localhost:4192/Tafsir` في Chrome أو Edge على حاسوب بكرت شاشة.

## ما يُسجَّل لكل سطر
1. هل اكتمل تنزيل النموذج؟ (نعم/لا)
2. الحجم الفعلي المنزّل كما يظهر في `chrome://gpu` أو من تبويب Network
3. الزمن الكلي للتنزيل بالثواني
4. سرعة التوليد التقريبية (عدد الكلمات ÷ زمن الظهور)

## العشرة أسطر
المهمة الآن: «بسّط هذا المقطع» على المقطع المسترجَع، لا سؤال حر.

| 10 | 112:1 | ابن كثير |  |  |

«أضاف» يعني رقمًا أو اسمًا أو سبب نزول أو حديثًا أو آية أخرى ليست في المقطع المعروض.
التطبيق يعرض تنبيهًا آليًا إذا وجد رقمًا أو إحالة سورة غير موجودة في المصدر (`findOutsideAdditions` في `src/lib/localModel.js`)،
لكن التنبيه ليس حكمًا كاملًا؛ الحكم النهائي بعين القارئ.

## قاعدة القرار
- كل الإجابات من النص بلا إضافات ← الزر يبقى مكشوفًا ويصبح «جاهز للدمج».
- أي إضافة أو خروج عن النص ← الزر يبقى مخفيًا بـ`VITE_ENABLE_LOCAL_SIMPLIFY=false` والاسترجاع هو الشغال.
