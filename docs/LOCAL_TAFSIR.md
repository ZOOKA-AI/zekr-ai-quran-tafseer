# ميزة «اسأل عن الآية» — التشغيل والاختبار

ميزة تجريبية على الفرع `feature/local-tafsir-small-model`. لم تُدمج في `main`.

## التشغيل

```bash
git fetch origin
git checkout feature/local-tafsir-small-model
npm install
npm run dev
```

ثم افتح العنوان الذي يطبعه Vite (عادةً `http://localhost:5173`) وانتقل إلى صفحة **التفسير** (`/Tafsir`).

## متغيرات البيئة

الميزة نفسها لا تحتاج أي متغير ولا أي مفتاح API.

باقي التطبيق يتصل بـ Base44. إن لم تفتح الصفحة أصلاً، أنشئ ملف `.env.local` في جذر المشروع:

```bash
VITE_BASE44_APP_ID=معرّف_تطبيقك
VITE_BASE44_BACKEND_URL=رابط_الخادم
```

## ما يجب أن تراه

1. **دون إنترنت، من أول تجربة:** الصفحة تفتح على الفاتحة، آية 1. بطاقة «اسأل عن الآية» تعرض نص ابن كثير مع سطر «المصدر: تفسير ابن كثير». تفسير الفاتحة كاملاً (ابن كثير، السعدي، الطبري) مرفق مع التطبيق في `public/tafsir-seed/`، فلا يحتاج شبكة.
2. **مع إنترنت:** اختر سورة أخرى. النص يُجلب من CDN مرة واحدة ثم يبقى محفوظاً على الجهاز.
3. **التبسيط:** إن كان WebGPU مدعوماً يظهر حقل السؤال وزر «نزّل النموذج الصغير وبسّط النص».

## كيف تعرف أن WebGPU مدعوم

- افتح Console في المتصفح (F12) واكتب: `!!navigator.gpu` — يجب أن تكون النتيجة `true`.
- للتأكد من وجود كرت شاشة صالح: `await navigator.gpu.requestAdapter()` — يجب ألا تكون `null`.
- في Chrome يمكنك أيضاً فتح `chrome://gpu` والبحث عن سطر WebGPU.
- إن لم يكن مدعوماً، تعرض البطاقة: «التبسيط الآلي يحتاج متصفحاً يدعم WebGPU» ويبقى نص التفسير ظاهراً.

استخدم Chrome أو Edge حديثاً على الحاسوب للتجربة الأولى. صفحة `localhost` تُعدّ سياقاً آمناً فيعمل WebGPU والتخزين.

## النموذج

| البند | القيمة |
| --- | --- |
| النموذج | Qwen2.5-1.5B-Instruct (1.5 مليار معامل، أوزان مفتوحة، Apache-2.0) |
| المعرّف في WebLLM | `Qwen2.5-1.5B-Instruct-q4f16_1-MLC`، والبديل `…-q4f32_1-MLC` إن لم يدعم الجهاز `shader-f16` |
| المكتبة | WebLLM `@mlc-ai/web-llm@0.2.85`، تُحمَّل من `esm.run` عند الضغط على الزر فقط |
| ذاكرة كرت الشاشة | نحو 1.6 غيغابايت (f16) أو 1.9 غيغابايت (f32)، بحسب قائمة WebLLM |
| حجم التنزيل | نحو 1 غيغابايت — تقدير من حجم النموذج والتكميم، لم يُقَس |
| زمن أول تنزيل | تقدير: 1–2 دقيقة على 100 ميغابت/ث، 7–10 دقائق على 20 ميغابت/ث |
| المرات التالية | يُحمَّل من ذاكرة المتصفح دون تنزيل؛ عادةً أقل من دقيقة |

المعرّف الفعلي المستخدم يظهر تحت كل إجابة.

## رسائل قد تظهر في Console

| الرسالة | المعنى | ما تفعله |
| --- | --- | --- |
| `tafsir-seed-http-404` | ملفات `public/tafsir-seed` غير موجودة | تأكد أنك على الفرع الصحيح |
| `tafsir-http-…` أو `Failed to fetch` عند جلب التفسير | لا إنترنت، أو CDN محجوب، لسورة غير الفاتحة | جرّب الفاتحة، أو اتصل بالشبكة |
| `tafsir-unexpected-shape` | الملف المُستلم ليس بالشكل `{text, ayah, surah}` | أرسل لي الرابط الذي فشل |
| `local model error: webgpu-unsupported` | لا يوجد WebGPU | جرّب متصفحاً أو جهازاً آخر |
| `local model error: no-model-available` | المعرّف غير موجود في نسخة WebLLM | أرسل لي الرسالة |
| `Failed to fetch dynamically imported module …esm.run…` | تعذّر تحميل المكتبة من CDN | تحقق من الشبكة أو مانع الإعلانات |
| أخطاء `QuotaExceededError` أو أخطاء Cache أثناء التنزيل | مساحة تخزين المتصفح لا تكفي | أفرغ مساحة، أو جرّب نافذة عادية لا متخفية |
| `Device lost` أو أخطاء `GPUDevice` / out of memory | ذاكرة كرت الشاشة لا تكفي | أغلق تبويبات أخرى أو جرّب جهازاً أقوى |
| 404 لآية بلا ملف | طبيعي: التفسير يشرحها ضمن آية سابقة، والكود يرجع إليها | لا شيء |

## معيار القبول قبل الدمج

اسأل عشرة أسئلة على آيات مختلفة وقارن كل إجابة بنص التفسير المعروض. إن أضاف النموذج معلومات ليست في النص أو كانت عربيته رديئة، يُخفى زر التبسيط ويبقى الاسترجاع وحده.
